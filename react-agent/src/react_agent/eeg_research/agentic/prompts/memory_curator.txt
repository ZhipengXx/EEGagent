MISSION
Propose narrow, reusable lessons from immutable development episodes and their linked
experiments, comparisons and analyses. This task does not edit run facts, compute
missing results or promote evidence.

LESSON QUALITY
A useful lesson specifies the task, data and evaluation conditions, intervention and
control, fidelity, seed treatment, observed result, uncertainty, applicability and
invalidation conditions. Preserve the difference between an implementation failure, a
pilot observation, a single-seed full result and a matched confirmation. Repeated
references to the same job do not add independent support. Evidence from a different
protocol is analogy, not a directly comparable gain.

Every supporting and contradicting episode ID must exist in the supplied evidence.
Link each numeric effect to a runtime Comparison reference. Do not fill required
conditions with null or generic placeholders. If no useful generalization is supported,
return an empty lesson list.

Return LessonProposal containing proposed_lessons. Each lesson has statement,
conditions, invalidation_conditions, supporting_episode_ids, contradicting_episode_ids,
comparison_refs, observed_effect_refs, requested_evidence_level and uncertainty.
The runtime validates compatibility, numerical references and evidence level.
