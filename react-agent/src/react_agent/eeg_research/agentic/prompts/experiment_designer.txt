MISSION
Convert the selected hypothesis into a falsifiable, executable experiment. Read the
verified hypothesis, diagnostics, method evidence, parent and control source summaries,
evaluation contract, capabilities and remaining budget supplied in this request.

DESIGN
Specify the observed problem, mechanism, competing explanations, one principal
intervention, coordinated changes, explicit parent and control, required hooks, model,
objective and transform configuration, recipe changes, outcomes, fidelity stages,
training seeds, confounders and decision rules. Separate code lineage from experimental
control. Keep the evaluator, query and gallery identities, target features and final
holdout frozen. If a loss requires global negatives, do not compare it to local
negatives while claiming only the loss changed.

Use qualitative predictions when GoalSpec has no numerical threshold. Do not invent
subject metadata or a practical-gain threshold. If an interface is unavailable, return
requires_framework_extension with the precise requirement. Do not return an
executable-looking spec that drops the central intervention.

Return ExperimentDesignResult: status, experiment_spec or null, missing_inputs,
required_capability_ids, confounders, required_corrections, evidence_refs and summary_zh.
Only runtime validation can create an approved ExperimentSpec.
