Use experiment_spec.implementation_requirements for the method's core promises.
Each item has a unique requirement_id, kind="implementation", core=true,
expected_behavior, real code_locations and verification. In loso_method_search
at least one core implementation requirement is mandatory. Use verification=
"source_review" for execution paths, optional-off behavior, loss-item gradients,

For a promised ordered window representation use "ordered_window_slots" and
the typed probe: input_module_path is the actual pool input boundary;
representation_module_path is the downstream module whose input consumes that

promised. A probe location must identify real named modules, not prospective
config text. Put hoped-for score improvements in hypothesis or a separate
kind="scientific_hypothesis" requirement; these are untested before training
and never implementation gates.

TIED FROZEN IMAGE TARGETS
When duplicate image IDs use identical frozen image vectors, check that
condition against the supplied training target evidence. Symmetric
averaged log-probability CE over same-image positives is algebraically equivalent
to the baseline batch-diagonal CE when repeated image rows are identical. It
does not change EEG/scale training gradients merely by making a mask. State a
mathematically distinct objective and falsifiable gradient-level effect if
designing another local multi-positive loss. Keep negative policy and frozen
training recipe. Do not relabel or overwrite a trained candidate; use a new candidate.

EXPLICIT PROBABILITY-LOSS SEMANTICS
Read objective_semantics_probe / objective_semantic_findings when provided.
A changed gradient proves only computation change. Positive-mass InfoNCE uses
log(total local mass)-log(all same-ID positive mass), includes the diagonal, and
specifies whether both directions are averaged. A negative-only denominator is
a decoupled loss; it is a possible research alternative, not this normalized
probability loss. EEG normalization changes the baseline logit geometry too.
Do not call negative-only mass total mass or attribute a compound objective
change solely to same-ID grouping. Preserve historical actual scores and code.
For the prospective objective_variant="positive_mass_symmetric_infonce", the
runtime checks this explicit definition: image-normalized but raw EEG logits;
all same-ID positives including the diagonal; all local items in the denominator;
symmetric directional mean. Unique IDs must reduce exactly to baseline, and an
all-same-ID local batch has finite zero loss. This is a new precise variant,
not a redefinition of a historical candidate. A different intended loss must state its
formula, normalization, positive membership and symmetry explicitly. Keep the
exact objective-off baseline callable and a new approved candidate identity.
