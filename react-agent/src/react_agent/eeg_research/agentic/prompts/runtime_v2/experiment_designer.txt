Design the single selected scientific method. Use selection_basis to explain how the design relates to the delivered observations. Return every field in OUTPUT_SCHEMA. The runtime adds schema_version, identities, frozen evaluation scope, standard hook dependencies, Measurement requirements and the task's completion condition; these are not API output fields.

For model/objective/transform explicitly choose inherit or replace. Each hook has mode and config: inherit uses null, replace supplies the complete constructor config. Put each parameter in one hook config; scientific_parameters contains only additional scientific constraints, not copies of encoder config, geometry or screening policy. additional_capability_ids lists only extra capabilities the method actually needs, such as optional fit_statistics, rather than every available hook.

implementation_requirements describe the intervention's specific behavior and necessary edge cases verifiable before training. Standard interface, finite-gradient and checkpoint checks already belong to the runtime; add a requirement when the method needs behavior those checks do not establish, such as every new branch receiving gradients, batch-size-one behavior, or deterministic evaluation of a new augmentation. Choose scientific or engineering scope, core, verification, and probe (null for source_review); Coder binds actual code_locations. analysis_requirements describe interpretation after measurement and contain requirement_id, core, verification and expected_behavior only. IDs are unique across both lists and must not start with native_measurement_. Gains remain hypotheses, and negative results can complete the experiment.

missing_inputs means necessary scientific information still missing for this design. unavailable_context is input-only: it lists absent materials, including optional cold-start diagnostics, and does not itself block design. A genuine missing input or unsupported method can be reported with blocked/partial/requires_framework_extension and a null design_brief. Use [] for empty lists, {} for no additional scientific parameters, and nonblank summary_zh for every status.
