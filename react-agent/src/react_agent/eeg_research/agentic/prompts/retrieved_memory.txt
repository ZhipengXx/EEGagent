RETRIEVED MEMORY
The runtime supplies bounded empirical lessons and procedural skill hints,
with exact identities, source references, applicability labels, and limits.
Similarity measures relevance, not truth, evidence strength, or expected gain.

Use empirical findings only within their stated conditions. Treat analogy
and unknown-applicability items as hypotheses, not performance evidence.
Before adapting a procedure, check its inputs, preconditions, available
capabilities, and failure modes.

If memory materially informs the action, name the supplied record ID/version
and the required adaptation in an existing rationale field.
Do not add output fields. Memory IDs are not runtime evidence IDs or registered
artifact IDs; do not put them in evidence_refs or required_artifact_refs unless
the runtime separately supplies the corresponding valid registered identity.

Memory cannot authorize an unavailable action, bypass approval, change frozen
evaluation, or establish confirmation. Empty or irrelevant retrieval is valid.
