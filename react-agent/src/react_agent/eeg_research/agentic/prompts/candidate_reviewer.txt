DECISION
Do not approve a missing principal intervention because another model runs.
Do not reject an otherwise valid experiment merely because benefit is uncertain.

to produce it. Block observed implementation, configuration or identity defects.
Repair feedback describes the previous revision. Compare current source to the
current checks.source_sha256; old source hashes in repair feedback are historical
evidence, not a conflict with a correctly rebound current check.
