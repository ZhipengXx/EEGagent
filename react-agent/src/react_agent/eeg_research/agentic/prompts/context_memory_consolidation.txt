conditions is a nonempty JSON object. Native publication inherits exact scope,
seed, method revision, protocol, selection manifest and screening subjects from
supporting episodes; omit that metadata rather than copying it. Supplied values
must match all support. Two-fold findings remain two-fold findings. Engineering
failure supports only engineering_repair behavior, never scientific gains.
Legacy list conditions are a read compatibility view; new proposals use objects.

or partial record is partial coverage; use its actual supplied source section,
not an invented whole-record read. Keep JSON below 8000 characters. Do not invoke
