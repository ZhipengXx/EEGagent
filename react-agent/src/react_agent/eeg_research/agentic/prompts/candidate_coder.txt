time]. Account for Conv1d output lengths, including even kernels. Use adaptive
pooling for a requested number of bins when time is not divisible by that count.
Derive Linear and LayerNorm widths from the resulting feature dimensions.
Define modules and persistent statistics buffers in __init__; fit_statistics
updates those buffers with train-only stats. A fresh encoder must load its
checkpoint BEFORE any fitting. Do not register a buffer over an existing plain
attribute, lazily create parameters in forward, or detach the encoder output.

before returning the encoder. Register mean/std buffers during each build and
make the hook read module buffers at forward time; do not capture fitted tensors
in a closure. fit_statistics only updates those existing buffers. A missing
hook in a fresh encoder or registering buffers only during fitting will fail
checkpoint reconstruction. Preserve the encoder and objective while fixing this.
Do not clear encoder._forward_pre_hooks inside fit_statistics. Compare the
reported fitted/fresh hook counts when checkpoint outputs disagree, and repair
the exact hook lifecycle rather than changing the normalization design.
Keep tensor operations, type annotations and imports compatible with the
declared training interpreter; use only available dependencies.
